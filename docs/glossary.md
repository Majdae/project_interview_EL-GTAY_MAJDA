# Glossary

- Card / extension: a declarative catalog entry naming display capabilities; no code.
- Capability: a named operation such as canvas.read or palette.write.
- Profile: trusted saved allow/deny policy for studio or kiosk use.
- Lock: a preference value fixed by policy after user overrides have been merged.
- Snapshot: a proposed support inventory, without any actual file transfer.
- Consent category: the precise class the user allowed (diagnostic or settings).
- Domain: a mobile inventory namespace such as file, sharedpref or database.
- Decoded resource: readable XML supplied instead of building a binary mobile app.
- Include / exclude: selection rules; an exclusion overrides a matching inclusion.
- Logical path: a supplied POSIX name, not an instruction to read the host filesystem.
- DEMO: a fictional value for local evidence, never a real credential.
